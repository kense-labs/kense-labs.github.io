1 分钟对接

1 分钟对接

装包、起控制面、doctor 通——先跑通再展开。

更新 2026-11-14 文档版本 1.0.0 默认

约一分钟：装上 @kense/krun，起控制面，看到 doctor 成功。先通再深挖。

装包

install.shbash
pnpm add @kense/krun

有平台 optional 包更好（如 @kense/krun-darwin-arm64）。没有时设 KRUN_BIN 指向本机 krun 即可。

跑通

准备两个环境变量，然后复制下面这段（Main 进程里）：

变量作用
KRUN_CONTROL_SOCK控制面端点路径
KRUN_DATA_DIR数据目录
main/quickstart.tstypescript
import {
  resolveKrunBinary,
  spawnKrunServe,
  KrunClient,
  CONTROL_ENDPOINT_ENV,
} from '@kense/krun';

const bin = resolveKrunBinary();
if (!bin) throw new Error('krun binary missing — install platform package or set KRUN_BIN');

const dataDir = process.env.KRUN_DATA_DIR!;
const endpoint = process.env[CONTROL_ENDPOINT_ENV]!;

spawnKrunServe({
  bin,
  dataDir,
  env: {
    [CONTROL_ENDPOINT_ENV]: endpoint,
    KRUN_DATA_DIR: dataDir,
  },
});

async function ready(ms = 15_000) {
  const until = Date.now() + ms;
  for (;;) {
    try {
      return await KrunClient.fromEnv().doctor();
    } catch (err) {
      if (Date.now() > until) throw err;
      await new Promise((r) => setTimeout(r, 50));
    }
  }
}

const health = await ready();
console.log('KRun is up', health);

spawnKrunServe 不会替你等就绪——上面的 ready() 会轮询 doctor。

你已接通

  1. 包已安装，resolveKrunBinary() 能解析到二进制。
  2. doctor 在超时内返回成功。

到这里，控制面已经活了。会话、工具、挂载都是下一步，不是这一分钟的拦路石。
