文档/ KRun/ v1.0.0/ 迁出本机旁路

迁出本机旁路

迁出本机旁路

从宿主直跑切到隔离运行时：哪些不变、放置与拨号怎么变。

更新 2026-11-14 文档版本 1.0.0 默认

读者：已经用本机旁路接过的 Web Main。还没跑通控制面？先 1 分钟对接。还没完整接线时走 接入 Main。

不变的

项说明
界面仍只吃产品状态与业务数据
启动入口仍由 Main 编排会话
会话协议仍是原来的产品会话格式
业务进程仍用工具名与稳定工作区路径

放置怎么变

项变更前变更后
决策默认本机旁路显式选旁路或隔离
缺端点不适用隔离模式下启动失败，不回退本机
发版默认本机旁路隔离运行时

下方是 Main 放置逻辑的 unified diff，再后面是变更前后对照。

会话拨号怎么变

变更前：Main 拉起本机进程并建会话。

变更后：Main 连 Runtime 给出的会话端点；会话协议不变。

可选能力

隔离路径上可由 Main 按合同启用：宿主能力（开会话前准备工具名）、工作区共享（share_id）、界面只读状态。方法见 控制面 API；写法见 调用配方。

迁完再查

  1. 发版放置为默认隔离或强制隔离。
  2. 缺会话端点时启动失败，无静默回退。
  3. 最小会话与断线行为符合预期。
  4. 界面仍只读产品状态字段。
  5. 不要把旁路时代的宿主路径硬塞进 guest 参数。
