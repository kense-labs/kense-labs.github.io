层可见不可见

Runtime隔离环境与中继产品业务语义

强制隔离下缺会话端点必须启动失败，不得静默回退本机旁路。

vm_resources/*、guest_shares/*、core_impl/* 只给 Main，不进界面。

版本钉扎

  1. 合同与包用 .vN；破坏性变更升主版本。
  2. CI 锁 stamp 与合同哈希。
  3. 新可选能力默认失败关闭，或只拒单个工具。
  4. 文档按 docs/runtime/<version>/ 分版；当前默认 1.0.0。

出门清单

  1. 目标平台二进制可执行，并与 MANIFEST.json（若有）一致。
  2. docs/index.html 可离线打开。
  3. 强制隔离下移除会话端点，启动必须失败。
  4. 无 Runtime 时，界面状态为不可用。
  5. 若启用能力：已开放的可用，未开放的被拒。
  6. 若启用共享：按 share_id 增删成功；越权被拒。
  7. Main 控制面冒烟通过（如 doctor、必要会话路径）。
