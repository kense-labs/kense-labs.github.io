控制面 API

控制面 API

方法、参数、错误码与状态面。按任务抄代码见调用配方。

更新 2026-11-14 文档版本 1.0.0 默认

读者：Web Main。本页是字段与错误码参考，不是教程。第一次？先 1 分钟对接。接线走 接入 Main；「先调谁、怎么写」走 调用配方。

面协议调用方用途
控制面krun.control.v1Web Main（@kense/krun）健康、会话、能力、共享、资源
会话工具面krun.tools.v1隔离环境内会话已开放工具的 list / call / cancel
产品状态面合同定义的状态接口界面只读（经 Main 映射）交接阶段、安装进度

没有公网 HTTP REST 控制面。控制面是本机双向流上的 一行一条 UTF-8 JSON。

角色可调用不可调用
界面产品状态字段@kense/krun、控制方法、端点原文
Web Main@kense/krun + 控制面把方法名或端点泄漏给界面
业务进程产品会话；工具名控制面；宿主绝对路径

窄对接优先方法见包内 contracts/narrow-dock-naming.v1.json。获准 guest 出站 未宣称（默认关网）。

协议

npm 客户端

推荐使用绑定端点的 KrunClient：

main/control-client.tstypescript
import { KrunClient, CONTROL_SCHEMA } from '@kense/krun';

const client = KrunClient.fromEnv(); // KRUN_CONTROL_SOCK
const result = await client.doctor();
void CONTROL_SCHEMA;
void result;

低级一行一请求仍可用：

main/control-call.tstypescript
import { controlCall, resolveControlEndpoint, CONTROL_SCHEMA } from '@kense/krun';

const endpoint = resolveControlEndpoint();
if (!endpoint) throw new Error('control endpoint missing');

const result = await controlCall(endpoint, 'doctor', {});
void CONTROL_SCHEMA;
void result;

端点

项约定
控制端点CONTROL_ENDPOINT_ENV（KRUN_CONTROL_SOCK）；未设置时落在 Runtime 数据目录
数据目录KRUN_DATA_DIR；未设置时为平台默认用户数据目录下的 krun
启动服务krun serve（二进制由 resolveKrunBinary() 解析）

隔离环境端点与帧上限见包内 contracts/local-endpoints.json（勿向界面暴露原文路径）。

请求包络

每条请求必须包含版本、不透明 id、方法名与参数对象：

control-request.jsonjson
{
  "v": "krun.control.v1",
  "id": "req-1",
  "method": "doctor",
  "params": {}
}

响应包络

成功：

control-response-ok.jsonjson
{
  "v": "krun.control.v1",
  "id": "req-1",
  "result": {}
}

失败：

control-response-error.jsonjson
{
  "v": "krun.control.v1",
  "id": "req-1",
  "error": {
    "code": "protocol_violation",
    "message": "…"
  }
}

错误码

控制面稳定错误码（error.code）：

码含义
invalid_package包校验失败
pin_mismatchpin / 摘要不匹配
backend_unavailable后端不可用
acp_negotiate_failed会话协商失败
protocol_violation请求不合法或缺字段
handoff_conflict交接冲突
handoff_failed交接失败
fail_closed失败关闭（含未实现路径）
unauthorized未授权
invalid_params参数非法
session_revoked会话已撤
provider_failedprovider 回调失败
timeout客户端超时（@kense/krun）
transport套接字 / 截断 / 非 JSON
missing_endpoint未设 KRUN_CONTROL_SOCK 或 endpoint 为空

能力子调用还可能返回其它字符串码；分支优先看 error.code / KrunControlError.code。

以下按分组展开。参数字段名与运行时 JSON 一致。

健康与包

doctor

探测 Runtime 健康与配置摘要。
参数{}
结果backends、packages、gaps、selection、os、arch；以及共享 / 资源 / Core 实现摘要（若启用）
注意全量结果供运维；界面只映射合同允许的状态字段

list

刷新并返回 harness 注册表。
参数无
结果revision、entries[]（harness、name、version、ok、…）、gaps[]

validate

校验安装包并写入 CAS。
参数path（必填）；expect（可选期望）
结果digest、id、version、name、status、progress[]
错误invalid_package、pin_mismatch

reclaim_orphans

回收孤儿会话目录。结果：{ "reclaimed": string[] }。

reclaim_pin / uninstall_pin

参数说明
pin目标 pin

结果含 ok、pin、以及是否移除 CAS / 源包等字段。

gc_pins

参数说明
need_bytes可选；需要腾出的字节
keep_unreferenced可选；是否保留无引用

会话生命周期

activate

打开可写产品会话。

参数说明
harness{ id, source, pin }；source 为 local_zip 或 cloud_acp
request_id必填；幂等键
task_id可选任务 id
workspace_bind / workspace_binding可选工作区绑定
tools_admitted可选已开放工具名
runtime_generation可选代际
host_capabilities可选：tools_admitted、network、expires_at_ms
host_tools_endpoint可选；须先完成 host_tools/prepare
结果说明
harness实际 harness
generation会话代际
stream_handle会话数据面句柄（仅 Main 持有）
backend后端标识
acp_version协商版本

cloud_acp 在当前版本失败关闭。发版路径使用 local_zip。

deactivate

参数说明
task_id任务 id
generation代际

结果：{ "ok": true }。

handoff_prepare / handoff_commit / handoff_abort

方法作用关键参数
handoff_prepare封存来源会话交接命令对象
handoff_commitseal 并打开目标task_id、request_id
handoff_abort中止并恢复空闲task_id、request_id

结果为交接回执（含阶段、代际等）。冲突时返回 handoff_conflict 或 handoff_failed。

宿主工具

SDK 类型化入口：client.hostTools.prepare / .discard。路径、沙箱、tree-kill 等执行在 Main 侧宿主工具桥完成，不在本包导出。

产品工具名（合同 host-six-tools.json）：Read、Write、Edit、Grep、Bash；Desktop / Browser 名见 HOST_TOOL_NAMES。Program 是合同占位，不在 SDK HOST_TOOL_NAMES 表。

host_tools/prepare

参数说明
task_id任务 id
runtime_generation代际（`string \number`）
workspace_binding工作区绑定
expires_at_ms可选过期时间
tools_admitted可选工具名列表（permission）；不等于路径授权

结果：HostToolsGrant（scope、authorization、可选 generation / host_tools_endpoint / expires_at_ms）。authorization 只留 Main，勿进界面或日志明文。

host_tools/discard

参数说明
task_id任务 id

清掉 control 上尚未被 activate 消费的 pending prepare。不撤销 Main 侧执行租约。

host_endpoint

参数说明
task_id任务 id
generation代际

结果：endpoint、session、authorization。仅 Main 使用。

host_call / host_cancel

参数说明
task_id任务 id
generation代际
call_id调用 id
name工具名
arguments参数对象

host_call 返回工具结果 JSON。host_cancel 取消对应在途调用；控制面不再认这笔调用，不证明远端子进程已死。

出站 Authz 与生命周期观测

egress/status · egress/admit · egress/revoke

无 KrunClient typed helper，用 client.call。SDK 常量：NARROW_EGRESS_AUTHZ、EGRESS_CLAIMED_DEFAULT（false）、EgressAdmitRef。

admit 只做授权意图，本身不开网。guest native 未具备时返回 77 / FailClosed，不等于产品出站 Pass。

lifecycle/events

Helper：client.lifecycle.events({ since_seq? })。结果含 events[]、next_seq。观测面不授予写权限。信封禁止绝对 host_path、明文 token、密码。

能力与目录

capabilities/open

参数说明
task_id任务 id
runtime_generation代际
workspace_binding工作区
capabilities能力描述数组
admitted已开放名单
execution可选：workspace、read_only

结果：lease 与 capabilities[]。

capabilities/close

参数：能力租约对象。结果：{ "closed": true }。

capabilities/call

在租约下执行能力。执行期可能在同一连接上出现内部 provider/call 回调；不要把 provider/call 当作独立产品 API 对外暴露。

capabilities/execute / capabilities/cancel

内置 Rust worker 执行 / 取消。参数为能力调用对象。

directories/grant / update / revoke / list

版本化目录授权的增改撤查。list 的参数为租约；其余为对应 grant / update / revoke 对象。

工作区共享

合同：krun-vm-identity.v1.json。控制面 拒绝 host_path 参数。

标识字符集：

字段规则
name（机器名）[A-Za-z0-9._-]{1,64}
share_id[A-Za-z0-9_-]{1,64}

业务侧看到的是含 share_id 的稳定 guest 路径，不是宿主绝对路径。

guest_shares/add

参数说明
name机器名
share_id共享 id

结果：share_id、guest，以及可选的回收字段。

guest_shares/remove

参数同 add。

guest_shares/list

参数说明
name机器名

结果：共享条目数组。

资源

合同：vm-resources.v1.json。set / adjust 只写 desired；不声称热扩容。运行中实例在变更后多为 needs_restart；需要生效时显式 recreate。

apply_state：applied | needs_restart | recreating | unavailable。

vm_resources/probe

无参数。结果：cpu_logical、mem_*_mib、disk_*、disk_root（仅标签）、partial。

vm_resources/defaults

无参数。结果：cpus、memory_mib、disk_mib、profile。

vm_resources/get

无参数。结果：desired、applied、apply_state、tracked_name。

vm_resources/set

参数说明
cpus1..32
memory_mib128..32768
disk_mib磁盘上限
profile可选：auto \manual
name可选机器名

vm_resources/adjust

至少提供一项资源字段；可选 name。

vm_resources/status

可选 name。结果在 get 基础上增加 probe、pressure。

vm_resources/events

参数说明
since_seq可选；默认 0

结果：events[]、next_seq。事件环容量 64。类型含 defaults_computed、desired_changed、needs_restart、recreate_finished、pressure。

vm_resources/recreate

参数说明
name机器名（必填）

显式停止再启动以使 desired 生效。

Core 实现

合同：core-impl.v1.json。v1 内置实现 id：default。省略或空字符串视为 default。

core_impl/list

无参数。结果：[{ "impl", "kind", "available" }]。

core_impl/get

无参数。结果：desired、applied、apply_state。

core_impl/set

参数说明
impl可选；空 → default
name可选机器名

未知 id → 失败关闭。

core_impl/status

可选 name。在 get 基础上增加 available、builtin。

会话工具面

协议：krun.tools.v1。在隔离环境内的工具通道上调用（路径由 local-endpoints 合同给出）。

方法作用
tools/hello探活
tools/list列出已开放工具
tools/call调用工具：params.name、params.arguments；帧内带会话与授权
tools/cancel取消：params.id 为在途 call id

典型错误：protocol_violation、method_not_found、busy、duplicate_id、unknown_tool、tool_failed、resource_denied、cancelled。

产品状态面

合同：upstream-tipc-handoff.v1.json。由宿主 Main 映射为界面只读状态；不是控制面方法。

状态方法输出要点
getHandoffStatusavailable、phase（idle \preparing \committed \aborted \unknown）、代际、时间、surface
getInstallProgressavailable、status（idle \installed \failed \unknown）、steps[]、last_error_code

界面不得出现控制方法名、端点或 pin 原文。vm_resources/*、guest_shares/*、core_impl/* 无 界面仪表盘。

合同作用
